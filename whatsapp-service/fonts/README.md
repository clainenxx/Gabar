# Font untuk kartu pesanan WhatsApp

Poppins (Bold 700, Regular 400, Light 300) — dipakai `order-card.js` lewat
Satori. Satori butuh file font TTF/OTF/WOFF (bukan WOFF2) dan membacanya
langsung dari folder ini, jadi TIDAK perlu font terpasang di server.

Poppins berlisensi SIL Open Font License 1.1 (boleh dipakai & disertakan
di project komersial). Sumber: https://fonts.google.com/specimen/Poppins
